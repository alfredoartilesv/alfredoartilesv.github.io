# alfredoartilesv.github.io

Personal CV site of Alfredo Artiles, a software engineer in rail and mobility. Static HTML, CSS and JavaScript, with no build step. Hosted free on GitHub Pages at https://alfredoartilesv.github.io

- Projects section is curated in `assets/config.js` (`only`, `privateRepos`).
- The CV PDFs in `assets/` are built from the LaTeX source repo (`cv_english_latex.pdf`, `cv_espanol_latex.pdf`).
- Design inspired by carnilove.ashfall.studio: parallax hero, scroll reveals, menu overlay.

Local preview: `python -m http.server` in this folder, then open http://localhost:8000
